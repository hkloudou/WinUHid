每次 `main` 分支构建并通过安装测试后，这里会自动更新为最新版本。

## 怎么用

1. 下载 `WinUHid-dev-test-kit.zip`，解压到一个文件夹
2. 右键 `install.cmd` → 以管理员身份运行
3. 右键 `selftest.cmd` → 以管理员身份运行，最后一行显示 `RESULT: OK` 即通过
4. 测试完，右键 `uninstall.cmd` → 以管理员身份运行

系统要求：64 位 Windows 10（2004 及以上）或 Windows 11。详细说明见压缩包里的 `README.txt`。
