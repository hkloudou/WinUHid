WinUHid 开发测试包（仅限测试机）
================================

这是自动构建出来的测试版本，用的是一次性的测试证书，不是正式签名。
不要发给用户，不要装在生产机器或日常办公机器上。

系统要求
--------
64 位 Windows 10（2004 及以上）或 Windows 11，需要管理员权限。
不需要开启"测试模式"，不需要关闭"安全启动"。

怎么用
------
1. 把整个压缩包解压到一个文件夹（不要在压缩包里直接双击）。
2. 右键 install.cmd，选择"以管理员身份运行"。
   看到 "OK - installed" 就是装好了。
3. 右键 selftest.cmd，选择"以管理员身份运行"。
   它会创建一个虚拟鼠标和一个虚拟键盘：
   - 鼠标指针会自己画一个小方框
   - 会模拟按一下左 Shift（不会打出任何字）
   最后一行显示 RESULT: OK 就是全部通过。
   开头几行会显示这台机器的测试模式（Test mode）和安全启动（Secure Boot）状态。
   Test mode 显示 off，才说明"普通机器不开测试模式也能用"。
4. 测试完，右键 uninstall.cmd，选择"以管理员身份运行"，
   会卸载驱动并删除测试证书。

出问题时
--------
把这几样发回来：
- selftest.cmd 窗口里的全部文字（或截图）
- 本文件夹里的 install.log
- C:\Windows\INF\setupapi.dev.log

文件说明
--------
WinUHid-dev-test-x64.msi   驱动安装包
WinUHid-dev-test.cer       本次构建的测试证书（只有公钥）
cert-thumbprint.txt        证书指纹，卸载时用来精确删除这张证书
install.cmd                信任证书并安装
selftest.cmd / .ps1        自检：创建虚拟鼠标和键盘并确认输入生效
uninstall.cmd              卸载并删除证书
lib\                       WinUHid.dll、WinUHidDevs.dll 及对应的 .lib
include\                   C/C++ 头文件

说明
----
- 虚拟鼠标键盘相当于插在这台机器上的真实硬件，输入进入的是"本机屏幕"那个会话。
  如果你是用 Windows 远程桌面（mstsc）连到测试机上跑 selftest，设备能创建成功，
  但指针不会动、按键也看不到，selftest 会显示 [WARN] 并注明这是远程桌面下的正常现象。
  要看到真实效果，请在本机屏幕前操作，或用 VNC、云厂商控制台这类直接显示本机屏幕的方式。
- 测试证书的有效期设为 100 年，测试包不会因为证书到期而失效。
  但它始终只是测试证书：install.cmd 每次运行都会先提示这一点，按任意键才继续。
- 每次构建的证书都不一样。换了新的包，要先用旧包的 uninstall.cmd 卸载，
  再用新包的 install.cmd 安装。
- 只有管理员权限的程序才能创建虚拟设备，这是驱动本身的访问控制，
  所以 selftest 也必须以管理员身份运行。
